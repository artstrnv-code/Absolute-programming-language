в APl, как и в любом другом языке, есть логическое ветвление if. пишется оно так

if (cond){
  # тут два отступа!
}

позволяет обрабатывать условия. например
AVInt a = input
if (a == 1){
  out 2
}

вывдете 2 только если введено 1

логические операторы
and, or, все по классике. но важно: нет приоритета. все обязательно указывать в скобках. например:
((a or b) and (c or d))

может выглядеть громоздко. но спасает от загадок

есть блоки else if (cond) и else
то же самое. пишется после основного if:

if (cond){

} else if (cond) {

} else {

}

блоков else if может быть сколько угодно. они являются проверкой условия
else -- один. он действует если не сработало ничего из вышеперечисленного

Важно. просчет идет сверху вниз. если написать два условия, которые одноврменно актвиирууются (например or), то актвируется то, что выше по коду
