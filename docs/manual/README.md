# Руководство APL

Это официальное пользовательское руководство по Absolute Programming
Language. Оно объясняет язык последовательно и простым языком, с небольшими
примерами.

Точный технический контракт реализованного синтаксиса находится в
[`../language.md`](../language.md), а текущее состояние компилятора и библиотек
записано в [`../status.md`](../status.md). Руководство, технический справочник и
реализация должны обновляться вместе.
