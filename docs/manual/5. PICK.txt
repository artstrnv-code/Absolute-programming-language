pick -- второй цикл в APL. вернее это даже не просто цикл, а перебор массива или значений
работает так:
pick (massive): current {
  # тело цикла
}
в скобках указывается массив или строка для перебора. после двоеточения переменная, в которую будет записыаться каждый элемент поочередно
в теле может быть что угодно. переменная (тут current) является VTime и потому имеет значение только "на время" перебор цикла. то есть обратившись так:
pick (massive): current {

}
out current
программа упадет с ошибкой, ведь уже забудет current

внутри тела цикла можно выполнять любые действия .как и с while. 

break и continue -- твои лучшие доузья. первый мгновенно выведет тебя из цикла "насильно", оборвет его, второй вернет в его начало (К проверке, или для pick к подбору следующего элемента). используются и там, и там
