начнем с самого базового в языке -- точка входа. можете просто скопировать:
AVInt std::main(){
  return 0
}

это главная функция языка. по ней компьютер понимает, откуда начать выполнение. возвращать из нее можно не только 0, но и любое число. более того, доступен возврат ошибки

return(ERR=[text][code])
возвращает ошибку с текстом text и кодом ошибки code. полезно для отладки. не является корректным завершением программы
