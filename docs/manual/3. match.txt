у if есть и старший брат -- match

match value {
  case 0 {
    out "zero"
  }
  case 1, 2 {
    out "one or two"
  }
  case 3..10 {
    out "from 3 to 10"
  }
  case default {
    out "other"
  }
}

и в самом примере все поведение расписано. он берет:
значение (переменной, выражения) value и подставляет под варианты ("кейсы")
case 0 -- конкретный пример. 
case 1, 2 -- аналог или (or) или |. для нескольких значений с одним результатом
3..10
для чисел. от a до b
case default -- для всех других ситуаций

и помните: городить match для каждой плюшки -- это дурно. используйте его для реально больших штук, а булев флаг легче расписать в if
