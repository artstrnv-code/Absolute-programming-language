while -- цикл с выходом по условию записывается так:
while (condition is true)(iterations){
  _
}
в первых скобках -- условие сравниваемое с true. во втором -- максимум повторений (-1 для бесконечного цикла)

например, зачем могут быть полезны такие циклы

AVInt x = 0
while (true)(100){
  x += 1
  out x
}

эта функция выведет 100 различных чисел от 1 до 100. если брать условия
AVInt y = input
AVInt x = input
while (x == y)(-1){
  out x
  out"\n"
  out y
}
а вот это бесконечный цикл который запускается если оба ввода одинаковых и постоянно их выводит так:
5
55
55
..
55

и так без остановки. в обычной консоли вывод идет потоком, но Studio может накапливать его в окне и постепенно занимать память. будьте аккуратны!

А можно ограничить тот же код:
AVInt y = input
AVInt x = input
while (x == y)(17){
  out x
  out"\n"
  out y
}
и он выведет наше значение только 17 раз, и ничего не сломается!

else:
в циклах он тоже есть. он выполняется если итерации не было ни разу. полезная штука. пишется схоже с ветвлениями

while (cond)(iters){

} else {

}

но есть также блок limit. пишется до else. уникален для while. срабатывает если израсходован лимит итераций. Полезно, если изначально по задумке до него все не должно было дойти.

while (cond)(iters){

} limit {
  out "лимит итераций исчерпан\n"
} else {
  out "цикл не начался\n"
}
