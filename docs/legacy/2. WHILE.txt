while -- цикл с выходом по условию записывается так:
while (condition is true)(iterations){
  _
}
в первых скобках -- условие сравниваемое с true. во втором -- максимум повторений (-1 для бесконечного цикла)

например, зачем могут быть полезны такие циклы

AVInt x = 0
while (true)(100){
  x += 1
  out x
}

эта функция выведет 100 различных чисел от 1 до 100. если брать условия
AVInt y = input
AVInt x = input
while (x == y)(-1){
  out x
  out"\n"
  out y
}
а вот это бесконечный цикл который запускается если оба ввода одинаковых и постоянно их выводит так:
5
55
55
..
55

и так пока память пк не забьется. будьте аккуратны!

А можно ограничить тот же код:
AVInt y = input
AVInt x = input
while (x == y)(17){
  out x
  out"\n"
  out y
}
и он выведет наше значение только 17 раз, и ничего не сломается!
